# PyTrader

## Description
PyTrader is a Python-based trading platform designed for high-frequency trading analysis. It features real-time market data fetching, technical analysis, and visualization.

## Installation
To set up PyTrader, follow these steps:
1. Clone the repository: `git clone https://github.com/kapra01/pytrader.git`
2. Set up a virtual environment: `python -m venv venv`
3. Activate the virtual environment:
   - Windows: `venv\Scripts\activate`
   - Unix/MacOS: `source venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt`

## Usage
Run the main script to start the application: `python src/main.py`
